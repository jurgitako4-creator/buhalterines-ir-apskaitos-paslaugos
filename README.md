# Buhalterinės ir apskaitos paslaugos

Vieno puslapio svetainė buhalterinių ir apskaitos paslaugų biurui. Sukurta mokymų metu kaip pavyzdys.

**Svetainė:** https://jurgitako4-creator.github.io/buhalterines-ir-apskaitos-paslaugos/

## Kas puslapyje

- paslaugos: buhalterinė apskaita, darbo užmokestis, mokesčių deklaracijos, finansinės ataskaitos, individualios veiklos apskaita, konsultacijos;
- darbo eiga keturiais žingsniais;
- kam tinka: individuali veikla, MB, UAB;
- dažni klausimai;
- kontaktų forma, kuri atidaro el. pašto programą su paruoštu laišku.
